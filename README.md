## 免备案、免实名、免监管是三件事，三条规则线

**ICP 备案**针对的是网站和域名能否在中国大陆境内公开提供访问。工信部只管大陆境内机房，服务器放在香港、美国、日本、新加坡这些境外节点，不在管辖范围，域名解析过去直接开 80/443 就能访问；阿里云、腾讯云的官方文档也是这么写的。反过来，未备案域名解析到大陆服务器，机房系统会自动拦截 80/443 端口，网站打不开。

**实名认证**针对的是购买者身份，解决“你是谁”。它跟服务器放在哪、要不要备案是两条平行规则。境外服务商通常邮箱注册就能下单，JustHost 的下单页也没有标注额外身份核验要求，是否需要补充材料以下单时页面提示为准。

境外服务器经常同时“免实名 + 免备案”，这是两个结果撞在一起，不是因果关系。不能因为没交身份证就推出不用备案，也不能因为免备案就以为服务商一定不核身份。

**内容监管**是第三条线，跟机房位置无关。免备案省掉的是流程时间，不是合规责任。违法违规内容、侵权内容、攻击性内容放在哪个机房都会被封停，境外节点同样要遵守机房所在地法律。

把这三层分开看，选机器时就知道自己在买什么：买的是“跳过备案流程”，不是“跳过所有规则”。

官方写的是不限流量、端口公平共享。公平共享意味着高峰期你和其他用户分同一个端口，跑不满标称值属于正常。没有“用到多少 GB 后限速”的条款。
